## I：GPT-5.6 有哪些变化

在你编写任何提示之前，先快速了解 GPT-5.6 的核心变化。

1. 它的 Token 效率大幅提升

GPT-5.6 使用比先前模型更少的输出 Token，便能达到前沿级别的性能。

2. 它更能读懂你的意图

GPT-5.6 能推断任务的深层目标和适当的投入程度，无需你把每一步都交代清楚。你仍需明确说明约束、审批边界和成功标准，但不必再如此细致地手把手引导模型。

3. 默认回答更短

这是行为上最显著的转变之一。GPT-5.6 在各类任务中的回答都比之前的模型简短：泛泛的开场更少、臆测性的分支更少、列表更短，答案与其背后理由之间的重复也更少。

4. 设计和前端判断力更强

GPT-5.6 能产出更精致、更好用的网站和应用，在布局、视觉层级与设计判断上都有明显提升。

5. 新的推理与执行模式

GPT-5.6 为最棘手的任务新增了超越 xhigh 的 `max` 推理强度，并带来全新的 Pro Mode（后文详述）。

6. 工具调用有了新的执行路径

GPT-5.6 可以自行编写并运行轻量程序，用于调用工具、处理结果、筛选中间输出；这一能力称为 Programmatic Tool Calling（程序化工具调用）。

7. 多智能体协作（Beta）

单个 GPT-5.6 实例现在可以并行协调多个子智能体，并汇总其结果，类似 Codex 的 ultra 模式。

## II：如何正确提示 GPT-5.6

1. 使用更短的提示

这是你最需要做出的调整。

OpenAI 的内部评估发现：将冗长、明确的系统提示替换为极简提示，可让得分提高约 15%，同时将总 Token 用量降低 60% 以上。

2. 清晰界定自主性与权限

GPT-5.6 可以主动且持续地推进任务，因此你需要界定每个请求实际授权它采取什么程度的行动。

使用 GPT-5.6 时，只要清楚说明希望模型止步于何处，以及它获准推进哪些事项。

一个重要提醒：不要在提示中反复写“先询问”“不要修改”或“等待批准”。这种重复反而可能触发不必要的权限检查，即使是安全且预期之内的操作也是如此。

3. 避免泛泛的指令

使用优先级指令——这能让 GPT-5.6 理解你的深层目标。

例如，如果你想要更短的回答，不要说“写短一点”，而应说“先给出结论”。

4. 语气

仅仅要求 GPT-5.6“更友好”或“更有同理心”，并不会带来显著改善。

这类泛泛的温暖语气指令，已不像对旧模型那样有效。

5. 保持轻量结构

GPT-5.6 受益于少量任务专属结构：一份轻量大纲，而不是强加给每个回答的完整模板。

只有在自己的测试证明确有必要时，才增加局部约束。

TL;DR：对 GPT-5.6 而言，少即是多。提示更短、权限边界更清晰，而不是反复警告；指令更具体，而不是模糊笼统。如今，过度设计提示更可能造成伤害而非帮助。

## III：新功能

GPT-5.6 推出的全部新功能概览。

1. Pro Mode

Pro Mode 适用于任何 GPT-5.6 模型（Sol、Terra 或 Luna），也适用于其支持的任意推理强度。

你无需切换到单独的“Pro”模型；只需保持现有模型选择，并在其上启用 Pro Mode 设置。

2. ChatGPT Work

ChatGPT Work 是 OpenAI 对标 Claude Cowork 的直接竞争产品。

Work 模式独立于常规的 ChatGPT 对话，旨在自动化你所在行业的实际工作流程。

![](https://pbs.twimg.com/media/HMz_hoEaAAEFWgo.jpg)

3. GPT-Live

OpenAI 新推出的高级语音提示功能。

带来更流畅的对话、实时语言翻译等能力。

4. 新的推理强度

GPT-5.6 现在支持六档推理强度：

None、Low、Medium、High、xHigh 和 Max。其中新增的 Max 位于 xhigh 之上，面向最复杂的任务。

你可以直接在 ChatGPT 的模型选择器中调整推理强度。

5. Hosted Sites

一种分享想法的新方式。

可通过网页版的 ChatGPT Work，或 ChatGPT 桌面应用的 Work/Codex 模式访问 Sites。

## IV：GPT-5.6 的最佳提示框架

这套框架适用于大多数提示，综合了以上各节的全部原则：

第 1 步：选择模型

GPT-5.6 分为三个层级：

- Sol：用于最困难的任务
- Terra：日常主力模型
- Luna：最快且最具性价比，面向高吞吐工作负载

第 2 步：设置推理强度

None/Low：基础提示

Medium：默认档位（适用于 MCP 调用、API 调用等提示）

High 或 xHigh：复杂任务

Max：最后手段（用于极其复杂的工作）

第 3 步：确定是否需要 Pro Mode

它独立于推理强度。

仅用于质量上的边际提升确实重要的任务。

第 4 步：构建提示

每个高质量的 GPT-5.6 提示都包含四个组成部分：

1. 预期成果：完成时具体应是什么样子
2. 约束：审批边界、不可发生的事、范围
3. 证据／成功标准：以何种证明或格式确认结果正确
4. 自主性策略：模型无需事先询问即可采取哪些行动

## V：GPT-5.6 的注意事项

- 缓存写入现在更贵，按未缓存输入价格的 1.25 倍计费。
- PTC 并不总是最佳选择。一次调用足以完成时，应跳过它。
- Pro Mode 成本更高，额外的后台工作都按标准 Token 费率计费。
- Sites 的部署 URL 始终指向生产环境，默认没有独立的预发布步骤。若想在正式上线前审阅，请先保存一个版本。
- GPT-5.4 将于 7 月 23 日停用，GPT-5.5 会继续可用。最好现在就迁移，而不是等待。
- 旧版 GPT-5.5 提示未必能顺畅迁移。请 GPT-5.6 重写你的工作流程，让新的 5.6 模型能更高效地工作。

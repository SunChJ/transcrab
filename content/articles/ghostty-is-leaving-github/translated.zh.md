# Ghostty 即将离开 GitHub

写下这些让我难过得有点不理性，但 Ghostty 将要离开 GitHub[1](#user-content-fn-3)。

我是 GitHub 用户 1299，2008 年 2 月加入。

从那以后，我每天都会打开 GitHub。每天，一天好几次，持续了 18 年多。超过我人生的一半。中间当然有少数例外（我很想看看数据），但我想每年不会超过一周。

GitHub 是最让我快乐的地方。我总会为它留出时间。经历艰难分手的时候？我把自己埋进开源里……在 GitHub 上。大学时凌晨 4 点，所有人都睡倒了？让我再提交一个 commit。蜜月时妻子还在睡？嗯，GitHub。这里一直是我最快乐、最想待着的地方。

甚至那些烦人的事也是！有些人在社交媒体上末日刷屏。我在这个词出现之前，就已经在末日刷 GitHub issue 了。度假时，我会收藏一些 GitHub 上的项目，准备研究。不只是源代码，还有开源软件的流程、其他维护者如何应对棘手情况，等等。信不信由你，我喜欢这些。

有人也许会觉得这很病态，但我的爱好、工作和热情刚好重合，而在我人生的大部分时间里，它们也都能住在互联网的同一个地方：GitHub。

你知道吗，我当初开始做 Vagrant（我的第一个成功的开源项目），很大程度上是因为我希望它能帮我拿到 GitHub 的工作？这不是什么秘密，我反复说过。第一次公开演讲介绍 Vagrant 时，我才 20 岁，还开玩笑说：“如果它足够好，也许 GitHub 会雇我！”

GitHub 曾是我梦寐以求的工作。我最终没能在那里工作（这不是他们的错）。但那就是我想去的完美地方。那里的工程师很棒，产品很棒，而且它是我每天都生活其中、呼吸其中的东西。直到现在仍然如此，而且这 18 年来一直如此。足够一个完整的人长大成人的时间，全都在 GitHub 上。

最近，我非常公开地批评 GitHub。我说过难听的话。我很愤怒。我伤到了别人的感情。我在发泄。因为 GitHub 每一天都在让我失望，而这件事对我来说很私人。私人到不理性。我爱 GitHub，爱到一个人不该这样爱一个东西的程度，所以我才对它生气。对于伤害到参与其中的人，我很抱歉。

这种感受已经持续很久了。但过去一个月，我开始记日记：只要某一天 GitHub 故障负面影响了我的工作能力[2](#user-content-fn-2)，我就在那一天旁边打一个“X”。几乎每天都有一个 X。在我写这篇文章的当天，因为 GitHub Actions 故障[3](#user-content-fn-1)，我大约 2 小时都无法做任何 PR review。如果它每天都把你挡在门外好几个小时，这里就不再是一个适合严肃工作的地方。

对我来说，它已经不再是一个有趣的地方。我想待在那里，但它不想让我待在那里。我想完成工作，但它不想让我完成工作。我想发布软件，但它不想让我发布软件。

我希望它变好，但我也想写代码。而我已经没法再用 GitHub 写代码了。抱歉。18 年之后，我必须离开。我希望有一天还能回来，但这必须建立在真实的结果和改进之上，而不是话语和承诺。

接下来几个月，我会分享更多关于 Ghostty 项目将迁往何处的细节。我们已经有计划，但我也仍在和多个提供方讨论，包括商业服务和 FOSS 方案。

移除我们对 GitHub 的所有依赖需要时间，我们已经制定了计划，会尽可能增量地推进。我们计划在当前 URL 上保留一个只读镜像。

我的个人项目和其他工作暂时还会留在 GitHub。Ghostty 是我、我们的维护者，以及我们的开源社区受影响最大的地方，所以这次变更会以它为重点。之后会走向哪里，我们再看。
